# FUTURE_DS_02
This project analyzes customer retention and churn patterns for a subscription-based business. The goal is to identify factors influencing customer churn, calculate customer lifetime value, and provide insights to improve customer retention.
# Features
Customer churn rate calculation
Customer lifetime value (CLV) analysis
Subscription duration analysis
Retention trend identification
Churn visualization using charts
# Technologies Used
Python
Pandas
Matplotlib
Dataset Fields
Customer ID
Subscription Months
Monthly Spend
Churn Status
# Output
Churn Rate (%)
Average Subscription Duration
Average Customer Lifetime Value
Churn Distribution Graph
Business Benefits
Understand customer behavior
Reduce customer loss
Improve retention strategies
Increase customer lifetime value
# How to Run
Install Python.
Install required libraries:
Bash
pip install pandas matplotlib
Run the program:
Bash
python churn_analysis.py
# Expected Result
The program displays churn metrics and generates a bar chart showing the distribution of retained and churned customers.
